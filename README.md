# Buber Breakfast

A REST API for managing breakfasts, built with .NET 6 following the freeCodeCamp course "Industry Level REST API using .NET 6" by Amichai Mantinband.

## About The Project

A CRUD API for breakfasts (create, read, update, delete), structured as an industry-level .NET solution: an API project, a contracts project (request/response models), documentation, and sample HTTP requests.

### Built With

- .NET 6
- ASP.NET Core
